# AI modules (post–Sprint 1)

This folder is reserved for the AI pipeline described in `docs/architecture.md`:
`digital_twin/`, `forecasting/`, `graph_ai/`, `physics_ai/`, `xai/`,
`synthetic_data/`, `reinforcement_learning/`, and `llm_assistant/`.

Sprint 1 ships the data foundation these modules will train on (see
`simulator/` and `database/schema.sql`); the modules themselves land in
later sprints.
